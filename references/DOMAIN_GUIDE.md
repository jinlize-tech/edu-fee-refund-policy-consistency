# 收费与退费规则一致性检查领域指南

## 业务问题

同一课包在价目表、合同、销售话术、系统设置和退款审批中可能出现不同折扣、有效期和退费标准。

## 产品解决方案

把课包、合同、价目表、优惠规则、退费制度与销售话术放入同一口径检查，生成差异表和统一规则建议。

## 专业能力边界

- **收费规则建模**：用于同一课包在价目表、合同、销售话术、系统设置和退款审批中可能出现不同折扣、有效期和退费标准。相关判断。
- **价格/赠课/有效期对比**：用于同一课包在价目表、合同、销售话术、系统设置和退款审批中可能出现不同折扣、有效期和退费标准。相关判断。
- **退费口径核查**：用于同一课包在价目表、合同、销售话术、系统设置和退款审批中可能出现不同折扣、有效期和退费标准。相关判断。
- **宣传与合同一致性**：用于同一课包在价目表、合同、销售话术、系统设置和退款审批中可能出现不同折扣、有效期和退费标准。相关判断。
- **异常情景测试**：用于同一课包在价目表、合同、销售话术、系统设置和退款审批中可能出现不同折扣、有效期和退费标准。相关判断。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `course_packages` | 课包清单及价格 | 是 | 每个课包应含名称、公开价格、有效期、赠课和优惠规则 |
| `contract_rule_summary` | 合同规则摘要 | 是 | 不得填入真实客户姓名或签名 |
| `published_price_list` | 对外价目表 | 是 | 渠道、价格、折扣、有效期和版本 |
| `sales_scripts` | 销售话术 | 是 | 可能影响收费或退费承诺的原话 |
| `refund_policy` | 退费制度 | 是 | 含起算日、扣费、赠课和审批流程 |
| `approval_process` | 审批流程 | 否 | 审批节点和责任角色 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

财务负责人与法律/合规人员应确认：收费、赠课、有效期、退费规则和对外口径的最终统一。未经确认的内容只能作为草案。

## 主要风险

正式退费规则仍需财务与法律人员确认；地区监管差异和合同条款需人工核验；不能替代交易系统配置。
